04 / STANCE

你是哪一腳在前？先分清 Regular / Goofy。

「前腳」指靠近雪板板頭的腳，與前刃／後刃完全是不同概念。

Regular：左腳在前

左腳靠近板頭、右腳靠近板尾。這是站姿名稱，不代表比較正確。

示意圖可切換。真實站姿以舒適、平衡與實際操作為準。
05 / BOARD SETUP

Binding 角度沒有萬用答案。

選擇站姿不是抄一組數字就結束，還要考慮站距、舒適感和個人滑行方式。

你的站姿由 4 個項目 組成
01前後腳

Regular / Goofy

02站距 Width

可從雪板參考站距測試

03角度 Angle

正角朝板頭；負角朝板尾

04偏移 Setback

固定器相對板中心的位置

TWO COMMON EXAMPLES
＋ / 0

前腳朝板頭、後腳較接近垂直，是 Burton 提到的一種初學起點。

＋ / −

俗稱 Duck Stance，對需要雙向滑行的玩法常見。

起點 ≠ 唯一正解。先合身與穩定，再由教練協助微調。
06 / FIRST MOVES

先練平地移動，再慢慢下坡。

Skating 是前腳固定、後腳在雪面推行；這和兩腳綁好直衝下坡不是一回事。

三件事先做到

  1. 在平坦、安全的區域練習。
  2. 膝蓋保持彈性，眼睛看行進方向。
  3. 能穩定移動、控制速度，再依教練指示進入低緩坡。
這裡是動作概念說明；真正的地形選擇與練習方式，應由現場教練指導。
07 / EDGE CONTROL

雪板最重要的兩條邊：Heel / Toe Edge。

雪板左右兩側的長刃能幫助你控制滑動和減速，不是「哪隻腳在前」的意思。

HEEL EDGE / 腳跟側刃

用腳跟側長刃控制滑行，常用在面向下坡的初學者練習。

TOE EDGE / 腳尖側刃

用腳尖側長刃控制滑行，常見於背向下坡的初學者練習。

!
術語檢查：前刃 ≠ 前腳

Toe / Heel 是雪板的兩條長邊；Regular / Goofy 才描述哪隻腳在前。

08 / FALLING LEAF

落葉飄：同一條刃，也能左右移動。

這個練習不是比誰下坡快，而是熟悉「往左／往右移動，再回到中央控速」。

① 練方向

在同一條刃上，用左右重心調整橫移方向。

② 練速度

回到中央時減速，先會停，再開始下一段。

09 / FIRST TURN

單次轉彎：讓雪板朝側邊走。

你可能看過 J-turn 或 C-turn 的叫法；不同教材的命名與安排不完全相同。

WHAT TO UNDERSTAND

轉彎是為了控速與轉向

當你能在低速下平衡並穩定控制單一刃，就可以在教練指導下理解轉彎如何從一個方向逐步帶到坡面側邊。

Burton 使用 Falling Leaf → C-turn 的表述；REI 介紹 J-turn、Traverse 再到連續轉彎。這份課程只保留兩者共同的基礎概念。
10 / LINKING TURNS

連續 S Turn：把一個個轉彎連起來。

能從一側轉到另一側，並持續控制速度，才算真正理解連續轉彎的目的。

1

每一個彎都能控速

不是朝落線直衝，而是讓轉彎幫助你調整速度與方向。

2

兩側轉彎穩定銜接

進入下一個彎時，雪板控制不能突然消失。

3

別把 S Turn 當成刻滑

初學的連續轉彎可能包含側滑；純刻滑（Carving）是另一個進階技術課題。

11 / MOUNTAIN SAFETY

上雪場第一守則：能停下來比滑得快重要。

以下是 NSAA《Your Responsibility Code》的重點摘錄；仍須遵守你所在雪場的規定。

01

保持控制，能避開人與障礙物。

02

前方或下坡滑行者優先，後方的人必須避讓。

03

不要停在視線死角或妨礙他人的地方。

04

起滑／進入雪道前先觀察上坡來人。

05

遵守雪場標示、封閉區域與纜車規範。

06

防止裝備失控滑走；發生碰撞要依規定通報。

重要：線上簡報只能補充觀念，不能取代實地授課。滑雪具有跌倒、碰撞與重傷風險。
