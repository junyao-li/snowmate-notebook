# 初學者學習地圖與教學順序

## 這份 HTML 的教學策略
從「裝備與安全」開始，再理解「站姿與固定器」，接著進行「滑行準備 → 兩側控刃 → 落葉飄 → 單次轉彎 → 連續轉彎」，最後用安全情境題檢查理解。

## 教學評量
1. 能分辨 Regular / Goofy 與 toe / heel edge（避免將前腳與前刃混為一談）。
2. 能說明落葉飄先練控制、連續轉彎需建立換刃與控速能力。
3. 能選出雪場優先通行與安全停留的正確做法。

## 範圍界定
這是一份概念入門教學，不提供一日學會 S Turn 的保證，也不提供高風險坡面中的即時動作指令。
