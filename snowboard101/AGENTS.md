# Snowboard 101 LLM Wiki 規則（schema）

1. `raw/` 是固定的來源閱讀筆記，絕不自動覆蓋；它們不是原文全文。原始連結、擷取日期和來源 ID 需保留。
2. `wiki/` 是可修改的知識頁面；每個教學事實都要能從來源 ID 追到 `raw/Sxx.md`。
3. Ingest 新來源：先確認來源與日期 → 新增 raw/Sxx → 更新或新增 wiki 概念 → 更新 wiki/index.md → 在 log.md 追加一筆 ingest。
4. Query：先讀 wiki/index.md，選相關概念頁面，核對來源後才輸出；如證據不足，應標待查證，不可補造數據或宣稱專業建議。
5. Lint：檢查失效來源、名詞對應、跨頁矛盾、孤兒頁、來源追溯、過度絕對化的說法；出錯時優先返回 wiki 節點而非整份重做。
6. 教學對象是完全新手。技術順序只代表此份教學設計，不代表唯一正式滑雪課程標準。
7. 安全底線：不能保證學會；不可把線上簡報當成實地教練或雪場現場規範的替代品。
8. HTML 每頁必須有 `data-source-ids`，每個來源 ID 必須存在於 raw；可回查 wiki 的來源對照。
9. `log.md` 採 append-only，只寫實際執行、觀察和結果，不補寫未做的測試。
