## 反思：錯在哪？檢查為何前移？

**最先、也是本次明確發現錯誤的節點**：`HTML 生成 → 來源註記`。第 9 頁產出後發現來源 ID 指向不存在的 S07。這次不能推論「最常出錯」的統計結果，因為只做了一次實作；若按本次紀錄回答，最明確的錯誤類型是來源 ID 填寫不一致。

**原先流程缺點**：先生成完整簡報才檢查引用，錯誤會殘留在成品中，若頁面多就不容易查找。

**修改後流程**：`Wiki index → 大綱＋來源清單 → 檢查 source manifest → HTML`。今後每產生一頁前，必須先為教學概念指定 Wiki 頁面與 S01～S06 的有效來源 ID；生成後再次比對。這把可自動辨識的錯誤提早攔截，減少整頁重做。
